# MiraBackpacks

Persistent personal storage for Paper 1.21.11 / Java 21.

## Current release

**v0.1.0**

Direct download:
https://github.com/FiveSOCE/Mira-Backpacks/releases/download/v0.1.0/MiraBackpacks-0.1.0.jar

All releases:
https://github.com/FiveSOCE/Mira-Backpacks/releases

## Features

- Persistent personal backpack inventory
- Permission-based size tiers: 18, 27, 36, 45 and 54 slots
- Admin backpack inspection
- ItemStack metadata preserved through Bukkit serialization
- Public Bukkit ServicesManager API

## Commands

- `/backpack` or `/bp`
- `/backpack inspect <player>`

## Build

`./gradlew build`

Output: `build/libs/MiraBackpacks-0.1.0.jar`
